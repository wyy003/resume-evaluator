# 📄 AI 简历评估工具

一个基于 OpenAI GPT 的智能简历评估系统，帮助 HR 快速分析简历与职位的匹配度。

## ✨ 功能特性

- **多格式解析**：支持 PDF 和 Word（.docx）格式简历解析
- **真实 AI 分析**：接入 OpenAI GPT-3.5-turbo API，提供专业的简历评估
- **智能关键词匹配**：
  - 动态关键词提取：从 JD 自动识别技术栈
  - 同义词匹配：支持 15+ 技术栈同义词识别（如 k8s → kubernetes）
  - 权重评分：核心技能 3 分，常规技能 2 分
  - 熟练度识别：精通 1.5x、熟练 1.3x、熟悉 1.0x、了解 0.7x
- **批量处理**：支持多文件同时上传，带进度条和统计面板
- **导出报告**：支持导出 Word 格式的分析报告
- **动态反馈**：基于实际匹配技能生成针对性建议
- **历史记录**：保存所有分析记录，支持搜索、排序、筛选
- **现代化界面**：简洁美观的用户体验，响应式设计

## 🚀 快速开始

### 1. 安装依赖

```bash
cd resume-evaluator
pip install -r requirements.txt
```

### 2. 配置 OpenAI API

在项目根目录创建 `.env` 文件（或直接在代码中配置）：

```bash
OPENAI_API_KEY=your_api_key_here
```

### 3. 启动服务

```bash
uvicorn main:app --reload --port 8000
```

服务将在 `http://localhost:8000` 启动。

### 4. 使用步骤

1. 打开浏览器访问 `http://localhost:8000`
2. 上传 PDF 或 Word 格式的简历（支持批量上传）
3. 填写职位描述（JD）
4. 选择使用真实 LLM 或 Mock 模式
5. 点击"上传并分析"
6. 查看分析结果，可导出 Word 报告

## 📊 评分逻辑

### 真实 LLM 模式
使用 OpenAI GPT-3.5-turbo 进行深度分析：
- 综合评估简历与 JD 的匹配度
- 分析候选人的优势、不足和改进建议
- 考虑技能匹配、经验相关性、项目质量等多个维度
- 提供详细的反馈和建议

### Mock 模式（测试用）
- **段落完整性**（20分）：教育 5分、工作 8分、技能 4分、项目 3分
- **关键词匹配**（30分）：智能同义词匹配，核心技能 3分/项，常规技能 2分/项
- **内容质量**（20分）：数字量化 8分、项目描述 7分、技能数量 5分
- **熟练度加成**：精通 1.5x、熟练 1.3x、熟悉 1.0x、了解 0.7x
- **随机波动**（±5分）：模拟真实 LLM 的输出波动

## 🛠️ 技术栈

- **后端**：FastAPI 0.104.1
- **AI 模型**：OpenAI GPT-3.5-turbo
- **数据库**：SQLite
- **文档解析**：pypdf 3.17.1, python-docx 1.1.0
- **前端**：HTML/CSS/JavaScript
- **模板引擎**：Jinja2

## 📝 注意事项

- 支持 PDF 和 Word（.docx）格式的简历
- 文件大小限制：10MB
- 使用真实 LLM 需要配置 OpenAI API Key
- API 调用会产生费用（约 $0.002-0.005/次）
- 建议先使用 Mock 模式测试功能

## 💰 API 成本

- 单次分析约消耗 1500-2000 tokens
- 成本约 $0.002-0.005/次
- 系统会显示每次分析的 token 使用量和成本
