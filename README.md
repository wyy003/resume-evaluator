# 📄 AI 简历评估工具

一个基于 AI 的简历评估系统，帮助 HR 快速分析简历与职位的匹配度。

## ✨ 功能特性

- **PDF 简历解析**：自动提取简历中的教育、工作、技能、项目等关键信息
- **智能匹配分析**：根据职位描述（JD）评估简历匹配度
- **多维度评分**：
  - 段落完整性（20分）
  - 关键词匹配（30分）
  - 内容质量（20分）
  - 随机波动（±5分）
- **动态反馈**：自动生成优势、不足、改进建议
- **历史记录**：保存所有分析记录，方便回顾
- **现代化界面**：简洁美观的用户体验

## 🚀 快速开始

### 1. 安装依赖

```bash
cd resume-evaluator
pip install -r requirements.txt
```

### 2. 启动服务

```bash
python main.py
```

服务将在 `http://localhost:8000` 启动。

### 3. 使用步骤

1. 打开浏览器访问 `http://localhost:8000`
2. 上传 PDF 格式的简历
3. 填写职位描述（JD）
4. 点击"上传并分析"
5. 查看分析结果

## 📊 评分逻辑

### 段落完整性（20分）
- 教育经历：5分
- 工作经历：8分
- 技能：4分
- 项目经历：3分

### 关键词匹配（30分）
从 JD 中提取技术关键词（如 Python、Java、React 等），每匹配一个加 3 分，最多 30 分。

### 内容质量（20分）
- 工作经历包含数字量化：8分
- 项目描述超过 200 字：7分
- 技能数量超过 5 个：5分

### 随机波动（±5分）
模拟真实 LLM 的输出波动。

## 🛠️ 技术栈

- **后端**：FastAPI 0.104.1
- **数据库**：SQLite
- **PDF 解析**：pypdf 3.17.1
- **前端**：HTML/CSS/JavaScript
- **模板引擎**：Jinja2
